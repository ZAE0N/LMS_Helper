# LMS Helper

외국인 유학생이 인하공전 LMS 안에서 학교 공지와 교안을 모국어로 이해하도록 돕는 확장 프로그램 (아이디어 제공: 카로프 파루흐 팀원)
2026 AID 아이디어 공모전 출품작

# 팀 정보

| 이름 | 역할 | 담당 | 폴더 | 개발 |
|---|---|---|---|---|
| 전정현 | 팀장 | PM, 확장 프로그램 개발 | `extension/` | 크롬 확장 프로그램 |
| 카로프 파루흐 | 팀원 | 기획, 서버 & 백엔드, 용어집 번역·번역 품질 검수 | `server/` | 번역·공지 수집·챗봇 서버 (FastAPI) |

작업 규칙과 API 형식은 `AGENTS.md` 참고

## 빠른 실행
1. 서버: `server/README.md`의 실행 순서대로 `uvicorn app.main:app --port 8000`
2. 확장: `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `extension/` 선택
3. LMS 탭 새로고침 → 확장 아이콘 클릭 → 사이드 패널
