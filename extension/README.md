# LMS Helper — 크롬 확장 프로그램

현재는 진단 화면(세션 API·교안 다운로드 확인)과 테마만 있음. 기능 화면은 사이드 패널에 추가.
서버 주소는 `config.js`와 `manifest.json`의 `host_permissions`에서 함께 바꾼다.

## 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
4. `https://lms-app.inhatc.ac.kr` 에 로그인한 탭을 **새로고침**
5. 툴바의 확장 프로그램 아이콘 클릭 → 오른쪽에 사이드 패널이 열림

## 확인할 것
| 버튼 | 성공 기준 | 실패하면 |
|---|---|---|
| 1. 로그인 세션으로 API 호출 | `"result": "세션 API 접근 성공"`과 수강 과목 목록 | 에러 메시지를 그대로 공유 |
| 2. 교안 파일 다운로드 | `"isPdf": true` | `via`, `status`, `finalHost`, `contentError`, `tried` 값을 공유 |

- 파일은 크기만 확인하고 어디로도 보내지 않습니다.
- 결과를 공유할 때는 이름과 과목명을 가리세요.

## 깔끔한 테마
- 사이드 패널의 체크박스로 켜고 끕니다(기본값: 꺼짐).
- 색·모서리·그림자·글꼴만 바꾸고 레이아웃은 건드리지 않습니다.
- 퀴즈·시험 페이지에서는 자동으로 꺼집니다.
- 화면이 이상하면 바로 끄고, 어느 페이지였는지 알려 주세요.
